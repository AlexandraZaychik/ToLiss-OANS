Only needed if the OANS map stays hidden behind the normal FF ND (see README.md -> Troubleshooting).
Copy the folder zz_A350_BTV_bridge into the plugins folder of your A350, for example
    X-Plane 12/Aircraft/addon aircraft/AirbusA350/plugins/zz_A350_BTV_bridge/64/win.xpl
and restart X-Plane. The script checks by itself which helper plugin draws late enough.
