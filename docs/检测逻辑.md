# FMS 信息检测逻辑

采集内容包括起飞机场 / 跑道、目的地机场 / 跑道和备降机场。采集要求飞机适配、供电及相应文字或 DataRef 接口可用。

## ToLiss / LR330

### 自动采集

- **开关与阶段：**`auto info from mcdu2`（INI：`fms_mcdu2_sampling`）默认关闭；开启后，且 ECAM / FWS 阶段为 **2、3、4** 时，通过 MCDU2 翻页采集起降机场、跑道和备降机场。
- **请求间隔：**首次满足条件时发出请求；后续自动请求至少间隔 **60 秒**，从上次请求发出时计时。失败后继续尝试，无固定次数上限。
- **开始时机：**等待两侧 MCDU 连续 **5 秒无按键活动**，并等当前采集结束。长按产生的持续输入也会重新计时。
- **输入避让：**入口检查发现 MCDU2 输入栏非空或含 `TMPY` / `TEMPY` 时，跳过本次采集，等待后续自动请求。
- **完成条件：**同一次有效读取取得完整起飞和目的地机场对后，停止自动请求。跑道、备降机场可为空；分次取得的两个机场不合并计算完成状态。INIT R1 / L2 直读和 R6 / SEC L4 手动采集也可满足此条件。
- **阶段刷新：**开关开启、MCDU2 接口就绪时，约每 **3 秒**读取一次 ECAM / FWS 阶段；直读和采集过程中按需刷新。

阶段离开 2～4 时停止自动采集，并恢复 MCDU2 目标页面；采集中遇到机组按键则取消本轮，把页面操作交还机组。供电或接口不可用时暂停采集，恢复后继续按条件调度。

自动采集完成后，后续信息由按键触发更新。切换采集开关、飞机 / 机场重载、切换适配器或禁用插件会清理缓存并重置完成状态。

### 按键触发

两侧 MCDU 均支持以下触发。主页面按该侧最近一次主页面键记录，包含其子页面；单独按主页面键只更新记录。

| 主页面 | 按键 | 读取内容 | 读取方式 |
| --- | --- | --- | --- |
| INIT | R1（LSK1R） | 起飞机场、目的地机场及备降机场 | 下一次插件回调直读当前操作侧 INIT A |
| INIT | L2（LSK2L） | 起飞机场、目的地机场及备降机场 | 下一次插件回调直读当前操作侧 INIT A |
| F-PLN | R6（LSK6R） | 活动计划的起降机场、跑道及备降机场 | 两侧按键静默 5 秒后，通过 MCDU2 翻页采集 |
| SEC F-PLN / SEC INDEX | L4（LSK4L） | 当前生效的活动计划信息 | 同 R6 |

**INIT R1 / L2 直读：**

- 各阶段均可使用，独立于 MCDU2 采集开关；直接读取页面字段，输入栏有内容也可读取。
- 遇到 `TMPY` / `TEMPY` 时，**5 秒后在同侧重读一次**，无需等待按键静默。重读时检查当前页面；其他读取失败直接结束。
- R1 / L2 均检查 FROM/TO 和 ALTN，分别更新有效字段；已有跑道按下方更新规则保留或清理。

**R6 / SEC L4 翻页采集：**

- 要求 MCDU2 采集开关开启，各阶段均可触发。等待期间两侧按键都会重置 5 秒静默计时。
- 入口检查发现输入栏非空或 `TMPY` / `TEMPY` 时，**最多重试 1 次**，至少等待 5 秒并重新满足静默条件。
- 页面超时、空计划、机场未读全、核对或恢复失败、采集中被普通按键打断，均结束本轮手动请求。再次按有效触发键可新建一轮；自动采集按自身条件独立调度。

翻页采集在页面核对及恢复完成后更新结果。恢复以记录的主页面为目标，A/C STATUS、INIT B 有专门恢复处理。关闭采集开关后，保留 INIT 直读功能。

### 信息更新

- **INIT R1 / L2 的 FROM/TO：**更新读到的机场，另一端保留原值。同一机场保留已有跑道；机场变更时清除该端旧跑道，目的地变更时同时清除旧备降机场。
- **INIT R1 / L2 的 ALTN：**更新备降机场；`----` 或 `NONE` 表示清空。字段无效时保留原值（目的地变更时先清除旧备降，再应用本页有效 ALTN）。
- **阶段 5 及以上：**起飞机场及起飞跑道保持原值，手动采集可继续更新目的地、到达跑道和备降机场。
- **翻页结果：**有效单端结果保留另一端已有信息；明确空计划、超时、核对 / 恢复失败或机组打断会清理相应缓存，阶段 5 及以上保留起飞端。

## Zibo 737

### 自动采集

无后台自动采集。飞机及接口可用时，飞行阶段约每 **3 秒**读取一次，供诊断使用。

### 按键触发

- 两侧 FMC 共用一次待读取；最后一次按键活动后 **3 秒**，直接读取起飞 / 目的地机场及跑道 DataRef。继续按键或长按会重新计时。
- 各飞行阶段均可读取，独立于 `auto info from mcdu2` 开关。采集通过只读 DataRef 完成。
- 每次按键触发一次读取，读取后结束；再次按键可重新触发。供电或接口不可用时取消待处理请求，恢复后重新按键。
- 每次读取替换旧结果，空值或无效字段清除对应信息；飞机中的航路变更在下一次按键触发的读取后更新到插件。
- 当前支持起降机场和跑道，备降机场暂未接入。
